Automatización Robótica de Inventarios (SIIA)

Módulo desatendido para Alta de Inventarios (opc=78) y Seguimiento de Inventarios (opc=82) por lotes desde Excel con evidencias fotográficas.

Playwright RPA Engine

Cargar Almacenes para Alta

Haz clic para seleccionar el Excel con los almacenes (.xlsx, .xls)

Plantilla

Instrucciones de Alta de Inventario

  • El archivo Excel debe incluir una columna con el encabezado Almacén o Nombre.
  • El bot seleccionará automáticamente la localidad CS ALMACEN 2022 en el módulo opc=78.
  • Recorrerá cada almacén, pulsará Generar y registrará si el corte se creó o si ya tenía un ajuste previo.
  • Al concluir, generará un archivo comprimido Altas_Inventario_SIIA.zip listo para descargar con todas las hojas oficiales de inventario.

Cargar Inventario para Seguimiento

Haz clic para seleccionar el Excel (ej. INV OCTUBRE 11.xlsx)

Plantilla

Características del Seguimiento Inteligente

  • Reconocimiento Multinivel: Empareja insumos por Lote, Código de Barras y Caducidad.
  • Paginación Autónoma: Si un almacén cuenta con múltiples hojas (hasta 15 páginas), el bot navega cada hoja, llena cantidades, da clic en Guardar y avanza hasta completar todas.
  • Activación de Celdas Ocultas: Dispara los eventos nativos de JavaScript para garantizar que el ERP de Abisalud guarde los cambios en base de datos.
  • Evidencia Fotográfica Pre-Cierre: Toma la captura fotográfica del almacén con la tabla llena de insumos, cantidades capturadas y la casilla Finalizado marcada antes del guardado final, asegurando que el comprobante muestre todos los datos y no la pantalla vacía de reinicio.
